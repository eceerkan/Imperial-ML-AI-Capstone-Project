# Reuse and provenance

Course-provided starter data and capstone presentation materials have been retained for project review. Their redistribution rights are not independently verified. Before making this repository public, confirm that the course permits redistribution or remove the course-owned files and link to their authorised source instead.

Original explanatory text and reconstructed example code in this package are offered for portfolio illustration. No open-source licence is asserted for third-party materials. Add an explicit licence only when the rights of each component have been reviewed.
